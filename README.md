# Debre Bisrat

Wudase Mariam recordings for each day of the week.

## Adding recordings

Open `recordings.js`, find the section and paste the audio link into `audio: ""`.
Audio files can also go in an `audio/` folder, e.g. `audio: "audio/tuesday-01.m4a"`.

Use .m4a or .mp3 (iPhones can't play .ogg).

## Links

- `/#monday`, `/#tuesday` etc. open that day
- no hash opens today
